# Contributing to the site

## Updating the website

The website's main codebase and the CD pipelines are 
in [cloud-native-suisse-romande/association-website](https://github.com/cloud-native-suisse-romande/association-website).
The source code from this repository is currently embedded in the main site.

1. Submit a pull request to this repository
2. Review & Merge
3. Trigger [this workflow](https://github.com/cloud-native-suisse-romande/association-website/actions/workflows/deploy.yml) on GitHub Actions

## Managing the schedule

You can manage the schedule in Sessionize if you have permissions.
The embedded CSS and JavaScript are also served from there.
